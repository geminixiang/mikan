# Mikan Release

Read [references/RELEASE.md](references/RELEASE.md) for versioning, changelog, publishing commands, and release verification when performing a release.

Publishing a GitHub release triggers npm publication. Confirm the intended version and release scope; keep unrelated work out of the release commit. Report the release URL and actual publication status, not just whether the release was created.
