# Evidence for how AGENTS.md is written (2026-09)

Public collections of AGENTS.md and CLAUDE.md files mostly select by project fame, not by whether a rule works. The only sourced catalog found was [marco-trotta1/awesome-agents-md](https://github.com/marco-trotta1/awesome-agents-md), which records each file's revision. Controlled studies are more useful:

| Study                                                                | Finding                                                                                                                                                                                                               | Applied to `AGENTS.md`                                                                                                                                                                                              |
| -------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Evaluating AGENTS.md](https://arxiv.org/abs/2602.11988)             | Context files do not raise task success on average and add over 20% inference cost; agents follow the instructions, but repository overviews do not help. Non-standard practices are what context files are good for. | Removed the directory overview and the toolchain line; kept conventions the code does not show.                                                                                                                     |
| [Guardrails Beat Guidance](https://arxiv.org/abs/2604.11088)         | Individually beneficial rules were scope constraints ("do not refactor unrelated code"); harmful ones were generic directives ("follow code style").                                                                  | Removed generic directives such as "follow nearby code and the lint configuration"; kept scope and boundary rules.                                                                                                  |
| [When "Do Not" Is Not Deny](https://arxiv.org/abs/2608.23550)        | Most written security rules have no enforcing control.                                                                                                                                                                | Grouped rules that have guards under "Enforced contracts", each naming its guard.                                                                                                                                   |
| [Why Does CLAUDE.md Keep Growing?](https://arxiv.org/abs/2608.11095) | Rules accumulate because their rationale is lost, which makes deletion risky.                                                                                                                                         | Each remaining rule states its reason.                                                                                                                                                                              |
| [Context Rot](https://arxiv.org/abs/2606.09090)                      | 23% of sampled repositories reference code elements that no longer exist.                                                                                                                                             | `src/test/doc-references.test.ts` fails on a missing path, link, or anchor in the agent guides, module READMEs, and `architecture.toml`. Its first run found a README reference to a deleted `src/vault/policy.ts`. |
| [Instruction Adherence](https://arxiv.org/abs/2605.10039)            | File size, instruction position, and file layout had no detectable effect on adherence; adherence fell as sessions grew longer.                                                                                       | Kept one file; cut length for maintenance and cost, not for adherence.                                                                                                                                              |

Removed as no-ops or enforced elsewhere: `.js` import specifiers (TypeScript `Node16` resolution rejects extensionless imports), "edit source, not `dist/`" (`dist/` is ignored), and the directory map, whose `src/agent/` entry no longer existed.
