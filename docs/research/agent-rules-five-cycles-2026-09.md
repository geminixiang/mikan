# Five AGENTS.md learning cycles (2026-09)

Method: read each repository's first-party agent instructions at the recorded commit, compare the specific rule with mikan's existing contracts, make one applicable change, and verify it before continuing. Rules tied to a foreign framework, package manager, platform, or repository governance were not imported.
