# Pi's codemode and MCP design, compared with mikan

Research date: 2026-10-04. Sources: Pi `main` at `200387122` (v1.0.2 + unreleased), its docs, the commits and issues that introduced the design, and one captured mikan model request from a local Slack E2E run on `afe6ea69`.

## How Pi saves tokens with codemode and MCP

Pi's position is that tool declarations, not tool calls, are the recurring cost: every declared schema is sent with every request. Its design keeps MCP declarations out of requests entirely and lets the model reach MCP through one `codemode` tool whose description does not change.

| Mechanism                         | What Pi does                                                                                                                                                                                                                                                                                                                                                                         | Source                                                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| Exposure per tool                 | `direct` (declared), `codemode` (default for MCP: callable from scripts, never declared or listed), `deferred` (declared after `tool_search` loads it), `hidden`. `codemode` and `deferred` both map to the core `deferred` exposure; they differ only in which tool the MCP extension activates.                                                                                    | `docs/mcp.md` "Control tool exposure"; `extensions/mcp/tools.ts` `toToolExposure`                        |
| Which discovery tool exists       | `codemode` is activated when a `codemode`-exposure server connects; `tool_search` only for `deferred` servers. With the default, the model sees no `tool_search`.                                                                                                                                                                                                                    | `docs/mcp.md`; `extensions/codemode/index.ts`                                                            |
| Stable `codemode` description     | Deferred tools are never listed, so the description is identical before and after servers connect and stays cached. Listed declarations share a 3,000-token budget (`codemode.inlineBudget`).                                                                                                                                                                                        | `docs/codemode.md`; `extensions/codemode/tool.ts` `createCodemodeDescription`                            |
| Direct tools are not repeated     | In the default `codemode.mode: "on"`, tools already declared to the model are not listed in the `codemode` description; each declared tool's own description gets one line: ``Codemode: `tools.<id>(args)` resolves to …``. `"only"` hides direct declarations and lists them in codemode instead.                                                                                   | `extensions/codemode/tool.ts` `prepareCodemodeLoadout`, `describeScriptCall`                             |
| Short prompt                      | Script reference moved to `docs/codemode.md`; one line per global in the description. A default GPT-5.6 request fell from about 5,300 to 3,300 tokens.                                                                                                                                                                                                                               | commit `6f1072cc0`                                                                                       |
| Servers, not tools, in the prompt | An `mcp_servers` system-prompt section lists each server once, with how it is reached and one line (≤250 chars) from `description` or the server instructions; the section is capped at 4,096 chars. When it changes, Pi appends the new section to the conversation instead of editing earlier messages, so the cache holds. Full instructions are read with `describeNamespace()`. | `extensions/mcp/index.ts` `renderServersSection`, `before_agent_start`; commits `1c7e7df76`, `e029c3ed0` |
| Discovery inside scripts          | `ALL_TOOLS`, `searchTools(query, {limit, namespace})` (BM25, default 8), `describeTool(name)` (TypeScript declaration), `describeNamespace(name)` (`{ description, instructions, tools }`).                                                                                                                                                                                          | `docs/codemode.md` "Globals"; `extensions/tool-search/tool.ts`                                           |
| Scripts get the whole result      | Every MCP tool declares a `CallToolResult` output schema; scripts receive `content`, `structuredContent`, and `isError`, **never truncated**. Only the model-facing direct result is limited.                                                                                                                                                                                        | `extensions/mcp/tools.ts` header and `convertMcpResult`; `docs/codemode.md` "Call tools"                 |
| MCP errors                        | `isError` is an error result for the model, but a script still resolves to the `CallToolResult` so it can decide. Other failures reject.                                                                                                                                                                                                                                             | `extensions/codemode/execute.ts` `toScriptValue`                                                         |
| Direct result limit               | Model-facing MCP text over 20 KB keeps its start and end around a truncation marker; the full text goes to a 0600 temp file.                                                                                                                                                                                                                                                         | `extensions/mcp/tools.ts` `limitMcpContent`                                                              |
| Script output limit               | `max_output_tokens` (default 10,000) keeps head and tail and spills the full text.                                                                                                                                                                                                                                                                                                   | `docs/codemode.md`; `execute.ts` `truncateOutput`                                                        |
| Nested calls use the pipeline     | `ctx.executeTool()` applies validation and `tool_call`/`tool_result` hooks (permission gates) to nested calls, tagged with `parentToolCallId`.                                                                                                                                                                                                                                       | commit `8562bcf66`; `execute.ts`                                                                         |
| Lazy connections                  | Servers connect in the background. Only `direct` tools hold the first prompt (up to 10 s); scripts wait only for the servers they name, or all servers when they search.                                                                                                                                                                                                             | `docs/mcp.md`; commit `e029c3ed0`, issue #10212                                                          |
| `store`/`load`                    | JSON values persist across scripts as `codemode-store` session entries on the branch.                                                                                                                                                                                                                                                                                                | `docs/codemode.md` "Store values"                                                                        |

For hosts built on the agent packages rather than the coding agent, which is mikan's case, Pi ships `packages/agent/examples/mcp-codemode`: MCP tools return `structuredContent` with `outputSchema`, nested calls go through `runToolCall()` so hooks apply, and the codemode tool hands scripts `structuredContent` when declared, else text.

Design history: the first version (#10040, `8562bcf66`) listed every MCP tool declaration in the codemode description. Reviewers pointed out this was less context-efficient than lazy tool search. `1c7e7df76` stopped listing MCP tools, counts, and instructions; `e029c3ed0` made declarations independent of connected servers and moved servers into the `mcp_servers` section after a 10-second first-prompt stall (#10212).

## mikan compared

| Area                                     | Pi                                                                             | mikan (`afe6ea69`)                                                                                                       | Gap                                                                                                                                                                         |
| ---------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sandbox                                  | `pi-codemode` QuickJS worker                                                   | Same package                                                                                                             | None                                                                                                                                                                        |
| MCP declarations in codemode             | Never listed                                                                   | Never listed (`codemode.ts`)                                                                                             | None                                                                                                                                                                        |
| Direct tools in the codemode description | Not repeated (mode `on`)                                                       | Every granted direct tool's declaration repeated, up to 12,000 chars                                                     | **14,232-char codemode description on every request** (captured request: 38,274 chars of tools, 37% of it codemode)                                                         |
| Default MCP exposure                     | `codemode`; no `tool_search`                                                   | `deferred`; `tool_search` and codemode both offered                                                                      | Extra tool and two discovery paths                                                                                                                                          |
| Server listing                           | `mcp_servers` one-liners, ≤4,096 chars; instructions via `describeNamespace()` | Full server instructions in the system prompt; no `describeNamespace()`                                                  | Instructions sent on every request (1,336 chars for OpenConnector in production)                                                                                            |
| Nested MCP result                        | Full `CallToolResult`, untruncated                                             | The direct-call guard runs first: scripts get an abbreviated digest and a spill path inside the sandbox they cannot read | **Scripts cannot filter what they never receive**, which defeats codemode's purpose for large results such as `search_actions` (10–30k chars, `mcp-token-usage-2026-09.md`) |
| Nested MCP `isError`                     | Resolves with `isError: true`                                                  | Throws                                                                                                                   | Scripts cannot inspect error payloads                                                                                                                                       |
| Direct MCP result                        | 20 KB head+tail, temp file                                                     | mikan digest (keeps keys and counts), spill                                                                              | Different but deliberate (`mcp-token-usage-2026-09.md`)                                                                                                                     |
| Nested call pipeline                     | `ctx.executeTool` / `runToolCall`                                              | `executeNested` with mikan's loop guard, cancellation, accounting                                                        | Equivalent; documented local exception                                                                                                                                      |
| Search                                   | BM25, limit 8                                                                  | Weighted keywords, limit 5                                                                                               | Minor                                                                                                                                                                       |
| Connection                               | Background, lazy                                                               | Connect and `listTools()` while building the runner                                                                      | Latency only                                                                                                                                                                |
| `store`/`load`                           | Persisted per branch                                                           | Per script                                                                                                               | Minor                                                                                                                                                                       |

## What to change, in order of token impact

1. Stop repeating direct tools in the codemode description (Pi's mode `on`): add the one-line script note to each direct tool instead. Saves most of the 14,232 chars on every request in every session with tools.
2. Give scripts the full MCP `CallToolResult` (output schema + `structuredContent`, `isError` resolved), and keep the bound only on the model-facing direct result.
3. Make `codemode` the default MCP exposure: no `tool_search` unless a server opts into `deferred`.
4. Replace full server instructions in the system prompt with Pi's `mcp_servers` one-line section, and add `describeNamespace()`.

Each change should be measured with the same captured-request method (request size per call and per task) before and after.
