## Supported modes

| Mode                        | Runtime                           | Workspace                   | Notes                               |
| --------------------------- | --------------------------------- | --------------------------- | ----------------------------------- |
| `host`                      | mikan host                        | host path                   | Trusted local development           |
| `container:<name>`          | existing Docker container         | user-managed mount          | Compatibility mode                  |
| `image:<image>`             | mikan-managed Docker              | mikan-managed mount         | Local managed isolation             |
| `agent-sandbox:<warm-pool>` | Agent Sandbox pod in Kata microVM | shared RWX `/workspace` PVC | Recommended production microVM mode |
| `cloudflare:<sandbox-id>`   | Cloudflare bridge                 | remote filesystem           | Experimental                        |

## Agent Sandbox deployment

mikan and Agent Sandbox run in the same Kubernetes cluster and mount one RWX workspace PVC. The mikan control plane uses the normal container runtime; only Sandbox pods use `kata-qemu`. See [`deploy/helm/mikan/README.md`](https://github.com/geminixiang/mikan/blob/main/deploy/helm/mikan/README.md).

The dedicated runtime image includes Playwright Chromium, Xvfb, and ffmpeg for browser automation, screen capture, and software video processing.
