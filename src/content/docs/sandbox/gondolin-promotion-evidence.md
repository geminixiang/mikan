# Gondolin distributed promotion evidence

This ledger maps the distributed-sandbox objective to evidence. It is intentionally
stricter than a feature checklist: repository tests prove implementation behavior,
while hardware, network, and storage claims require evidence from the release
environment. A mock or single-host result never satisfies a two-machine row.

Last audited: 2026-07-17.

## Promotion boundary

- `image:*` is the preferred single-machine managed sandbox and retains its durable
  host workspace projection.
- `gondolin:remote` is the distributed provider under evaluation.
- `gondolin:default` remains a local development and diagnostics profile.
- The current remote contract is one active mikan coordinator with many workers, not a
  highly available multi-control-plane.

## Required release-environment sequence

1. An operator supplies at least two explicitly authorized SSH worker targets, a
   worker-reachable gateway address, host/worker shared-workspace paths, and the worker
   runtime entry path.
2. Run `scripts/preflight-gondolin-fleet.sh <worker-a> <worker-b>` and retain its
   timestamped output. This proves prerequisites only.
3. Capture authenticated Admin diagnostics and verify distinct workers, protocol 2,
   acceptable clock skew/uncertainty, healthy workspace probes, and expected capacity.
4. Exercise certificate and credential rotation plus the deployment's explicit network
   policy.
5. Inject worker restart, gateway restart, full partition, half-open transport, renewal
   response loss, and mount degradation. Retain lease epochs, fence deadlines, process
   exits, placements, and workspace marker history.
6. Run a sustained two-machine soak with concurrent placements and repeated lifecycle
   transitions.
7. Re-run diagnostics and deterministic quality gates against the exact candidate.

## Decisions and inputs still required

1. **Cross-WAN durability contract**: choose either a same-LAN/VPC-only initial
   promotion using shared POSIX, or require generation snapshot + epoch/CAS persistence
   before any promotion. Mutable NFS across WAN is not an option.
2. **Control-plane availability contract**: confirm that one supervised coordinator is
   sufficient, or require multi-control-plane HA.
3. **Authorized test environment**: provide the two worker targets and network/storage
   coordinates. Existing unrelated SSH hosts must not be discovered or used implicitly.

Until the open decision and applicable environment rows are resolved,
`gondolin:remote` remains a preview and this ledger must not be marked complete.
