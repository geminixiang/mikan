## 命令速查

| 命令                                               | 用途和范围                                                                                    |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `/login` / `/pi-login`                             | 打开有效期 15 分钟的登录/vault 链接。仅限 DM。                                                |
| `session` / `/session` / `/pi-session`             | 打开当前会话查看器。仅限 DM。                                                                 |
| `/new` / `/pi-new`                                 | 重置当前会话。仅限 DM。                                                                       |
| `/model` / `/pi-model [provider/model[:thinking]]` | 显示或切换当前对话模型。思考级别：`off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。 |
| `/auto-reply` / `/pi-auto-reply on\|off\|status`   | 控制当前群组/频道中的自动回复。                                                               |
| `stop` / `/stop`                                   | 停止匹配的活动运行。在 Slack 上，优先使用文本形式，以保持话题本地路由准确。                   |
| `/admin` / `/pi-admin`                             | 打开有效期 30 分钟的管理 portal。                                                             |
| `/extensions` / `/pi-extensions`                   | 列出全局和对话扩展、版本及其提供的技能。                                                      |
| `/sandbox` / `/pi-sandbox`                         | 显示当前管理的 image 沙箱限制和工作区挂载模式。                                               |
| `/pi-sandbox boost`                                | 应用配置的 boost 限制，直到管理的容器停止。                                                   |
| `/pi-sandbox private\|full`                        | 持久保存对话的 image 工作区挂载模式。`full` 会暴露整个工作区。                                |

<Aside type="note" title="平台注册命令">
  原生 slash commands 也必须在平台中注册。Slack 示例 manifest 包含 `/pi-login`、`/pi-session`、
  `/pi-new`、`/pi-model`、`/pi-auto-reply`、`/pi-sandbox`、`/pi-extensions` 和 `/pi-admin`。 Discord
  在启动时注册 application commands。Telegram 使用通过 long polling 处理的 bot commands。
</Aside>

## 共享 vault 命令

所有 vault 命令都仅限 DM：

| 命令                          | 效果                                                   |
| ----------------------------- | ------------------------------------------------------ |
| `/login shared list`          | 列出共享登录配置文件。                                 |
| `/login shared create <name>` | 打开创建共享配置文件的登录链接。                       |
| `/login shared update <name>` | 打开更新共享配置文件的登录链接。                       |
| `/login shared delete <name>` | 删除共享配置文件。                                     |
| `/login copy <name>`          | 将共享配置文件复制到当前对话 vault。匹配的值会被覆盖。 |

共享配置文件是由运维人员管理的凭证。通过 `sandbox.defaultSharedVault` 自动继承仅限符合条件、基于成员身份信任的 image/Cloudflare 对话；GitHub 等开放触发表面不会继承它。

## Web portals

管理、登录/vault 和会话 portal 使用同一个 HTTP 服务器。生产环境请配置公开 base URL：

<Steps>

1. 设置外部可访问的 URL：

   ```bash
   export LINK_URL="https://mikan.example.com"
   ```

2. 可选设置监听端口；存在 `LINK_URL` 时默认为 `8181`：

   ```bash
   export LINK_PORT=8181
   ```

3. 仅本地测试时，只设置 `LINK_PORT`。mikan 绑定到 `127.0.0.1`，并返回
   `http://localhost:<port>` 下的链接。

</Steps>

Capability URL 是 bearer secret。不要将其粘贴到共享频道、日志或 issue tracker 中。登录链接 15 分钟后过期，并在写入凭证时被使用；管理链接有效期为 30 分钟；会话链接有效期为 24 小时。进程重启会使所有未过期链接失效。

有关路由级权限，请参阅 [Portal 身份验证和 capability 模型](/zh-cn/portal-auth-model/)。
