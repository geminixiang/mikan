  `docker:*` 不是可用模式；请改用 `container:*` 或 `image:*`。
</Aside>

## 支持模式

| 模式                                                        | 执行位置              | Vault env injection | Vault key 语义               | 备注                                                                               |
| ----------------------------------------------------------- | --------------------- | ------------------- | ---------------------------- | ---------------------------------------------------------------------------------- |
| `host`                                                      | 宿主机                | 不注入              | 可存，但执行时不用           | 最适合本地开发；不把 vault env 放进 host process                                   |
| `container:<name>`                                          | 现有 Docker container | 注入                | `container-<name>`           | one container one vault；多人共享同一 container 就共享该 vault                     |
| `image:<image>`                                             | mikan 管理的 Docker   | 注入                | generated conversation vault | 当前最推荐的隔离模式；`1 conversation = 1 vault = 1 container`                     |
| `firecracker:<vm-id>:<host-path>[:<ssh-user>[:<ssh-port>]]` | Firecracker VM        | 注入                | generated conversation vault | Alpha 超早期；VM 需自行启动，workspace 需在 VM 内挂到 `/workspace`，当前不建议使用 |
| `cloudflare:<sandbox-id>`                                   | Cloudflare Worker     | 注入                | generated conversation vault | Experimental；需自行部署 `@cloudflare/sandbox` bridge，host workspace 不会自动同步 |

## 能力差异

`image:<image>` <Badge text="推荐" variant="success" /> 是当前主要开发与推荐的 sandbox 模式；其他模式保留为本地开发、兼容、或实验用途，部分能力不会补齐。

| 能力                                 | `host`   | `container:<name>` | `image:<image>` | `firecracker:*` | `cloudflare:*` |
| ------------------------------------ | -------- | ------------------ | --------------- | --------------- | -------------- |
| command 执行                         | ✅       | ✅                 | ✅              | ✅              | ✅             |
| mikan 管理 runtime lifecycle         | 不适用   | ❌                 | ✅              | ❌              | ❌             |
| per-conversation container / runtime | ❌       | ❌                 | ✅              | 需自行管理      | bridge 衍生 id |
| per-conversation vault env           | ❌       | ❌                 | ✅              | ✅              | ✅             |
| vault file 自动投影 / bind mount     | ❌       | ❌                 | ✅              | ❌              | ❌             |
| workspace 自动挂载                   | host     | 需自行挂载         | ✅              | 需自行挂载      | ❌             |
| private workspace mount mode         | 不适用   | ❌                 | ✅              | ❌              | ❌             |
| idle auto-stop / recreate            | 不适用   | ❌                 | ✅              | ❌              | ❌             |
| CPU / memory default limits          | ❌       | ❌                 | ✅              | ❌              | ❌             |
| `/pi-sandbox boost`                  | ❌       | ❌                 | ✅              | ❌              | ❌             |
| agent `sandbox` tool 设置 limits     | ❌       | ❌                 | ✅              | ❌              | ❌             |
| 推荐程度                             | 本地开发 | legacy / 兼容      | 主线            | alpha           | experimental   |
