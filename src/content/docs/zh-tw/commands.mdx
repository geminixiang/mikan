## 指令速查

| 指令                                               | 用途與範圍                                                                                             |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `/login` / `/pi-login`                             | 開啟 15 分鐘有效的 login/vault 連結。僅限 DM。                                                         |
| `session` / `/session` / `/pi-session`             | 開啟目前的工作階段檢視器。僅限 DM。                                                                    |
| `/new` / `/pi-new`                                 | 重設目前工作階段。僅限 DM。                                                                            |
| `/model` / `/pi-model [provider/model[:thinking]]` | 顯示或切換目前對話的模型。Thinking levels：`off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。 |
| `stop` / `/stop`                                   | 停止相符的執行中工作。在 Slack 上建議使用文字形式，讓 thread-local routing 保持準確。                  |
| `/pi-auto-reply <on\|off>`                         | 開啟或關閉目前 Slack channel 不需 mention 的回覆。                                                     |
| `/admin` / `/pi-admin`                             | 開啟 30 分鐘有效的管理 portal。                                                                        |
| `/sandbox` / `/pi-sandbox`                         | 顯示目前 sandbox 的限制，以及這個 office 的 visibility。                                               |
| `/pi-sandbox boost`                                | 套用設定的 boost 限制，直到受管理的 sandbox runtime 停止。                                             |
| `/pi-sandbox visibility`                           | 回報這個 office 生效中的 visibility 與其來源。                                                         |
| `/pi-sandbox visibility <private\|default>`        | 把這個公開頻道縮為 private office，或清除該覆寫。見下方 [Office visibility](#office-visibility)。      |

`/pi-sandbox` 只適用於受管理的 sandbox runtime：在 `host` 或 `container:<name>` 模式下，它會回覆這個指令需要 `image:*`。

### Office visibility

Visibility 跟隨 Slack 對話類型（ADR 0008）：公開頻道是 public office，其他所有 office 都能在 `/workspace/public/` 唯讀它，且它可寫入共用的 `MEMORY.md` 與 `skills/`；私人頻道、DM、群組 DM 與外部共享頻道是 private office，只有自己看得到。`/pi-sandbox visibility` 是 admin 的逃生口，只允許模型認可的唯一調整：把公開頻道視為 private。admin portal 中每個 office 也有同一個開關。

| 字詞      | 效果                                                                             |
| --------- | -------------------------------------------------------------------------------- |
| `default` | 清除覆寫；跟隨 Slack 對話類型。                                                  |
| `private` | 把這個公開頻道視為 private。對 DM 或私人頻道沒有額外效果，它們本來就是 private。 |

變更會在下一則訊息時生效，屆時 sandbox runtime 會以新的 mount 重建；既有的 container 內容會被保留。對話忙碌時切換會被拒絕。底層的 `office.visibility` 欄位請見[設定](/zh-tw/configuration/)。

<Aside type="note" title="平台指令註冊">
  原生 slash commands 也必須向平台註冊。指令清單位於 `src/adapters/commands/manifest.ts`：Discord 的
  application commands 與 Telegram 的指令選單會在啟動時由它派生，Slack 的路由也辨識清單中的 `/pi-*`
  名稱。由於 Discord 會拒絕長度超過 100 個字元的 option description，清單中的參數說明會由 command
  測試檢查長度。Slack 的 `/pi-login`、`/pi-session`、`/pi-new`、`/pi-model`、`/pi-sandbox`、
  `/pi-auto-reply` 與 `/pi-admin` 也必須註冊在 Slack App manifest。
</Aside>

## 共享 vault 指令

所有 vault 指令都僅限 DM：

| 指令                          | 效果                                                      |
| ----------------------------- | --------------------------------------------------------- |
| `/login shared list`          | 列出共享 login profiles。                                 |
| `/login shared create <name>` | 開啟建立共享 profile 的 login 連結。                      |
| `/login shared update <name>` | 開啟更新共享 profile 的 login 連結。                      |
| `/login shared delete <name>` | 刪除共享 profile。                                        |
| `/login copy <name>`          | 將共享 profile 複製到目前對話的 vault。相符的值會被覆寫。 |

共享 profiles 是由 operator 管理的憑證。透過 `sandbox.defaultSharedVault` 自動繼承僅限符合資格的 membership-trust image/Cloudflare 對話；GitHub 等 open-trigger surface 不會繼承。

## Web portals

Admin、login/vault 與 session portals 使用同一個 HTTP server。Production 環境請設定公開 base URL：

<Steps>

1. 設定外部可存取的 URL：

   ```bash
   export LINK_URL="https://mikan.example.com"
   ```

2. 可選擇 listen port；存在 `LINK_URL` 時預設為 `8181`：

   ```bash
   export LINK_PORT=8181
   ```

3. 僅限本機測試時，只設定 `LINK_PORT`。mikan 會綁定 `127.0.0.1`，並回傳
   `http://localhost:<port>` 下的連結。

</Steps>

Capability URL 是 bearer secret。請勿貼到共享頻道、日誌或 issue tracker。Login 連結會在 15 分鐘後過期，並在寫入憑證時消耗；admin 連結有效 30 分鐘；session 連結有效 24 小時。程序重新啟動會使所有尚未使用的連結失效。

各 route 權限請參閱 [Portal 驗證與 capability 模型](/zh-tw/portal-auth-model/)。
