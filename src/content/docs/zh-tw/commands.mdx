## 指令速查

| 指令                                               | 用途與範圍                                                                                             |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `/login` / `/pi-login`                             | 開啟 15 分鐘有效的 login/vault 連結。僅限 DM。                                                         |
| `session` / `/session` / `/pi-session`             | 開啟目前的工作階段檢視器。僅限 DM。                                                                    |
| `/new` / `/pi-new`                                 | 重設目前工作階段。僅限 DM。                                                                            |
| `/model` / `/pi-model [provider/model[:thinking]]` | 顯示或切換目前對話的模型。Thinking levels：`off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。 |
| `/auto-reply` / `/pi-auto-reply on\|off\|status`   | 控制目前群組／頻道中的 auto-reply。                                                                    |
| `stop` / `/stop`                                   | 停止相符的執行中工作。在 Slack 上建議使用文字形式，讓 thread-local routing 保持準確。                  |
| `/admin` / `/pi-admin`                             | 開啟 30 分鐘有效的管理 portal。                                                                        |
| `/extensions` / `/pi-extensions`                   | 列出全域與對話 extensions、版本及其提供的 skills。                                                     |
| `/sandbox` / `/pi-sandbox`                         | 顯示目前受管理 image sandbox 的限制與 workspace mount 模式。                                           |
| `/pi-sandbox boost`                                | 套用設定的 boost 限制，直到受管理 container 停止。                                                     |
| `/pi-sandbox private\|full`                        | 保存對話的 image workspace mount 模式。`full` 會公開整個 workspace。                                   |

<Aside type="note" title="平台指令註冊">
  原生 slash commands 也必須向平台註冊。Slack 範例 manifest 包含 `/pi-login`、`/pi-session`、
  `/pi-new`、`/pi-model`、`/pi-auto-reply`、`/pi-sandbox`、`/pi-extensions` 與 `/pi-admin`。Discord
  會在啟動時註冊 application commands。Telegram 使用透過 long polling 處理的 bot commands。
</Aside>

## 共享 vault 指令

所有 vault 指令都僅限 DM：

| 指令                          | 效果                                                      |
| ----------------------------- | --------------------------------------------------------- |
| `/login shared list`          | 列出共享 login profiles。                                 |
| `/login shared create <name>` | 開啟建立共享 profile 的 login 連結。                      |
| `/login shared update <name>` | 開啟更新共享 profile 的 login 連結。                      |
| `/login shared delete <name>` | 刪除共享 profile。                                        |
| `/login copy <name>`          | 將共享 profile 複製到目前對話的 vault。相符的值會被覆寫。 |

共享 profiles 是由 operator 管理的憑證。透過 `sandbox.defaultSharedVault` 自動繼承僅限符合資格的 membership-trust image/Cloudflare 對話；GitHub 等 open-trigger surface 不會繼承。

## Web portals

Admin、login/vault 與 session portals 使用同一個 HTTP server。Production 環境請設定公開 base URL：

<Steps>

1. 設定外部可存取的 URL：

   ```bash
   export LINK_URL="https://mikan.example.com"
   ```

2. 可選擇 listen port；存在 `LINK_URL` 時預設為 `8181`：

   ```bash
   export LINK_PORT=8181
   ```

3. 僅限本機測試時，只設定 `LINK_PORT`。mikan 會綁定 `127.0.0.1`，並回傳
   `http://localhost:<port>` 下的連結。

</Steps>

Capability URL 是 bearer secret。請勿貼到共享頻道、日誌或 issue tracker。Login 連結會在 15 分鐘後過期，並在寫入憑證時消耗；admin 連結有效 30 分鐘；session 連結有效 24 小時。程序重新啟動會使所有尚未使用的連結失效。

各 route 權限請參閱 [Portal 驗證與 capability 模型](/zh-tw/portal-auth-model/)。
