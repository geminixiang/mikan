本指南約 15 分鐘就能讓機器人回覆你的訊息。示範使用 Telegram（只需要一個 token）。你需要 Node.js 24.15 以上與 Docker。最後附上其他平台與用 PM2 常駐執行的連結。

## 前置需求

- Node.js `>=24.15.0`
- 一組 Anthropic API key（或其他支援 provider 的 key）
- 一個 Telegram 帳號

<Steps>

1. 安裝 mikan：

   ```bash
   npm i -g @geminixiang/mikan
   ```

2. 執行互動式設定：

   ```bash
   mikan onboard
   ```

   三個問題——聊天平台（及其 token）、LLM provider（及其 API key）、sandbox image——會產生 `~/.mikan/settings.json`、`~/.mikan/mikan.env`（0600）與 `~/.mikan/ecosystem.config.cjs`。選推薦的 image 即可。選擇自訂 OpenAI 相容端點（vLLM、proxy）時也會寫出 `~/.mikan/models.json`。非互動式 stdin 只會寫出設定模板。所有欄位請參閱[設定](/zh-tw/configuration/)。

   Key 也可以直接用環境變數提供（`<PROVIDER>_API_KEY`，例如 `ANTHROPIC_API_KEY`）；env 檔只是它們的持久化位置，pm2 模板會載入它。

   Onboarding 不會寫入任何 office policy：visibility 跟隨平台對話類型。Telegram 私訊是 private office，Docker sandbox 會讓每個 office 的檔案只屬於它自己。

3. 建立 Telegram 機器人。傳訊息給 [@BotFather](https://t.me/BotFather)，送出 `/newbot`，依提示操作並複製它回傳的 token：

   ```bash
   export TELEGRAM_BOT_TOKEN="123456:ABC-..."
   ```

4. 拉取 sandbox image，並在前景啟動 mikan：

   ```bash
   docker pull ghcr.io/geminixiang/mikan-sandbox:latest
   mikan --sandbox=image:ghcr.io/geminixiang/mikan-sandbox:latest
   ```

   image 約 900 MB，第一次拉取要等幾分鐘。working directory 預設為 `~/.mikan/workspace`，並會自動建立；在旗標後面傳入路徑即可改用其他位置。

   在那個 workspace 裡，每個對話都有自己的 **office**：一個存放該對話記憶、附件、工作階段記錄、skills 與工作區的目錄。Office 目錄是以 office key（`v1-telegram-…`）命名，而不是原始 chat id，因此要查看哪個 office 對應哪個對話，請使用 `mikan office list`。

   如果啟動失敗，執行 `mikan env`：它會依平台與功能分組，列出 mikan 讀取的所有變數與各自目前的狀態。缺少平台 token 時，mikan 會直接結束，並在訊息中指出需要設定的變數；`mikan --help` 則列出所有旗標。

5. 在 Telegram 開啟與機器人的私訊並傳送訊息。私訊會直接觸發 agent，幾秒內應該就會收到回覆。

</Steps>

<Aside type="tip" title="讓它持續執行">
  關掉終端機後也要讓 mikan 繼續執行，請參閱[部署](/zh-tw/deployment/)： `pm2 start
  ~/.mikan/ecosystem.config.cjs` 會在 PM2 底下執行同一個指令。
</Aside>

## 下一步

- **改用 Slack、Discord 或 GitHub** — 每個平台需要各自的憑證；請參閱 [Slack 最小設定指南](/zh-tw/slack-bot-minimal-guide/)、[Discord 接入層](/zh-tw/platform-adapters/discord/)與 [GitHub 接入層](/zh-tw/platform-adapters/github/)。
- **正式使用的隔離** — 拉取預建的 sandbox image 並以 `--sandbox=image:...` 啟動；請參閱 [Image sandbox](/zh-tw/sandbox/image/)。
- **提供 agent 工具所需的憑證** — 在私訊中輸入 `/login` 可開啟 vault portal 存放 API key 與 OAuth 憑證；請參閱 [Vault](/zh-tw/sandbox/vault/)。
- **以服務方式執行** — PM2 設定、升級與健康檢查請參閱[部署](/zh-tw/deployment/)。
- **完整設定與指令** — [設定](/zh-tw/configuration/)與[聊天指令](/zh-tw/commands/)。
